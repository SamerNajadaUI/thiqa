# قائمة الثقة اليومية

موقع بينزّل كل يوم 3 قسائم، **آمنة** و**شبه آمنة** و**خطيرة**، وكمان أعلى 10 توقعات احتمالاً بكرة القدم والسلة والتنس. كل توقع معه نسبته الحقيقية، وفي سجل علني لكل النتائج. الموقع بيتحدث لحاله كل يوم الساعة 6 الصبح بتوقيت عمّان، بدون سيرفر.

## الأسواق اللي بيدرسها

| السوق | أمثلة |
|---|---|
| الفائز | فوز ريال مدريد |
| فرصة مزدوجة (كرة قدم) | ريال مدريد ما بيخسر، أو "ما في تعادل" |
| مجموع الأهداف/النقاط، بكل الخطوط | أكثر من 0.5 / 1.5 / 2.5 أهداف، أقل من 4.5، أكثر من 210.5 نقطة |
| أهداف/نقاط كل فريق | السيتي يسجل أكثر من 1.5 |
| الهانديكاب، بكل الخطوط | السيتي ‎-1.5، الثاندر ‎-7.5 |
| الفريقين بيسجلوا | نعم / لا |

البرنامج بيتخطى الأسواق اللي ما بنقدر نصحّحها تلقائياً من النتيجة النهائية، مثل الكورنرز والكروت والشوط الأول والنتيجة الدقيقة. كمان بيستبعد التوقعات اللي أودزها أقل من 1.04 (مثل "أقل من 7.5 أهداف")، لأنها ما بتزيد ربح القسيمة إشي. بتقدر تغيّر هالحد من `min_leg_odds`.

## كيف بيدرس كل توقع

كل توقع بيمر على 5 طبقات، وكل طبقة بتعطي إشارة معه أو ضده:

1. **إجماع السوق:** من كل شركة بناخذ الاحتمال (1 ÷ الأودز)، بنشيل هامشها، وبناخذ الوسيط بين الشركات.
2. **الشركات الأدق:** Pinnacle وBetfair هم الأدق بالعالم لأنهم بيقبلوا رهانات المحترفين. إذا رأيهم أقل من الإجماع، هاي إشارة ضد التوقع.
3. **حركة الأودز:** البرنامج بيسحب أودز 48 ساعة، وبيحفظ لقطة كل يوم. لما المباراة توصل، بيعرف إذا احتمالها طلع أو نزل خلال 24 ساعة. النزول القوي معناه إنه فلوس المحترفين ضد التوقع.
4. **نموذج إحصائي (كرة القدم):** من مباريات الموسم الحقيقية بيحسب أهداف كل فريق على أرضه وبرّا، مع وزن لآخر 5 مباريات، وتعديل للتعب إذا فريق لعب قبل 3 أيام والثاني مرتاح. بعدين بيحسب احتمال كل نتيجة ممكنة (Poisson مع تصحيح Dixon-Coles للنتائج القليلة)، ومنها احتمال كل سوق.
5. **إحصائيات المباراة:** الفورمة، سجل الأرض وبرّا، الترتيب، المواجهات المباشرة، الشباك النظيفة، والمباريات اللي ما سجل فيها الفريق.

**الاحتمال النهائي** = السوق والشركات الأدق، مدموجين مع النموذج بوزن 15% (الوزن بيقل إذا الموسم لسا بأوله).

**الفلترة:** أي توقع بينشال من القسائم إذا:
- النموذج أقل من السوق بـ8 نقاط أو أكثر،
- أو السوق نزل ضده 3 نقاط بـ24 ساعة،
- أو أكثر من نص الإشارات ضده.

**"ليش؟":** تحت كل توقع بالموقع في قائمة أسباب حقيقية بالأرقام، وتحذيرات إذا في إشي ضده، وعدد الإشارات اللي معه.

إحصائيات كرة القدم متوفرة لـ: الدوري الإنجليزي، والإسباني، والإيطالي، والألماني، والفرنسي، والهولندي، والبرتغالي، والبرازيلي، والتشامبيونشيب، ودوري الأبطال. الدوري السعودي والسلة والتنس تحليلهم من السوق والشركات الأدق وحركة الأودز بس.

## القسائم

- **الآمنة:** 3 مباريات من أقوى التوقعات. احتمالها الكلي حوالي 80%.
- **شبه الآمنة:** 4 مباريات، كل توقع حوالي 86%، والاحتمال الكلي حوالي 55%.
- **الخطيرة:** 5 مباريات، كل توقع حوالي 72%، والاحتمال الكلي حوالي 20%. الأودز تقريباً 4–6.

كل قسيمة بتاخذ توقع واحد بس من كل مباراة، وبتفضّل التوقعات اللي إشاراتها الداعمة أكثر. الأرقام كلها بتتغير من `config.json` ← `coupons` و`analysis`.

## التشغيل (حوالي 15 دقيقة، وبتزبط من الموبايل)

1. **مفتاح الأودز:** سجّل على [the-odds-api.com](https://the-odds-api.com) وخذ المفتاح.
2. **GitHub:** اعمل repository جديد وخليه **Public**، وارفع كل ملفات المجلد عليه (Add file ← Upload files). انتبه إنه مجلد `.github` لازم ينرفع كمان.
3. **المفاتيح:** Settings ← Secrets and variables ← Actions ← New repository secret:
   - `ODDS_API_KEY`: مفتاح the-odds-api.com
   - `FOOTBALL_DATA_KEY`: مفتاح مجاني من [football-data.org](https://www.football-data.org/client/register) (بيوصلك على الإيميل)
4. **الموقع:** Settings ← Pages ← Deploy from a branch ← `main` و `/docs` ← Save.
5. **أول تشغيل:** Actions ← Daily picks ← Run workflow. ومن بعدها بيشتغل لحاله كل يوم.

## التحديث

- **كل يوم الساعة 6 الصبح (عمّان):** قسائم جديدة. هاد التشغيل الوحيد اللي بيصرف رصيد الأودز.
- **كل ساعة:** النتائج المباشرة والنهائية، وتصحيح القسائم، والشعارات، من ESPN مجاناً. القسائم نفسها ما بتتغير خلال اليوم، عشان السجل يضل صادق.
- **بالموقع نفسه:** المباريات الشغالة بتتحدث كل دقيقة، والصفحة بتجيب آخر بيانات كل 5 دقايق.

شعارات الفرق جاية من ESPN، والتنس بيظهر فيه علم بلد اللاعب. الفرق اللي ما إلها شعار (مثل اليوروليغ) بيظهر مكانها أول حرفين من اسمها.

## الرصيد: مجاني ولا مدفوع؟

The Odds API بيحسب "كريدت" لكل طلب:
- الأسواق الأساسية (الفائز، المجموع، الهانديكاب) لكل دوري: كريدت لكل سوق.
- الأسواق الإضافية (الفريقين بيسجلوا، كل خطوط الأهداف، أهداف كل فريق): لازم تنطلب لكل مباراة لحالها، وكل سوق بكريدت.
- النتائج لكل دوري: 2 كريدت.

| | الخطة المجانية (500 بالشهر) | خطة مدفوعة |
|---|---|---|
| `max_credits_per_run` | 16 | 300 أو أكثر |
| `extra_markets_events_per_run` | 4 (إذا ضل رصيد) | 40 |
| النتيجة | قسائم أغلبها من الفائز والمجموع والهانديكاب | كل الأسواق لأغلب المباريات |

مع الخطة المجانية الموقع بيشتغل، بس الأسواق الإضافية رح تكون لعدد قليل من المباريات. إذا بدك "كل الاحتمالات" فعلاً، الخطة المدفوعة ضرورية. وبكل الحالات البرنامج بيوقف لحاله قبل ما يتعدّى الحد.

## الإعدادات (`config.json`)

| الإعداد | شو بيعمل |
|---|---|
| `soccer_leagues` / `basketball_leagues` | الدوريات (أسماءها من قائمة الرياضات بموقع The Odds API) |
| `markets` | الأسواق لكل رياضة: `featured` لكل الدوري، و`extra` لكل مباراة |
| `coupons` | لكل قسيمة: عدد المباريات `legs`، الاحتمال الكلي المستهدف `target_total`، وأقل وأعلى احتمال لكل توقع |
| `min_leg_odds` | أقل أودز للتوقع (1.04) |
| `top_list_size` | عدد قائمة "أعلى 10" |
| `window_hours` | قديش لقدّام بيدوّر (24 ساعة) |

## تصحيح نتيجة يدوياً

إذا مباراة ما انحسمت لحالها (مثلاً بالتنس)، حط نتيجتها النهائية بـ`results_overrides.json` باستخدام رقم المباراة (`event_id`) من `docs/data/history.json`:

```json
{ "رقم-المباراة": "2-1" }
```

البرنامج رح يصحّح كل التوقعات والقسائم المرتبطة فيها. وبتقدر كمان تحط رقم توقع واحد (`id`) مع `hit` أو `miss` أو `void`.

## تجربة على جهازك

```bash
python engine/run.py --demo               # بيانات تجريبية
ODDS_API_KEY=xxxx FOOTBALL_DATA_KEY=yyyy python engine/run.py   # بيانات حقيقية
python -m http.server -d docs 8000        # وافتح localhost:8000
```
