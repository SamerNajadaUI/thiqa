# أبو عودة للآيفون

تطبيق iOS حقيقي، بيفتح أبو عودة شاشة كاملة، وفيه سحب لتحت للتحديث وشاشة "ما في نت".
بيبنيه GitHub لحاله، وبيحطه بصفحة **Releases** كملف `AbuOdeh.ipa`.

## التركيب على تلفونك (بدون متجر وبدون Xcode)

1. نزّل **Sideloadly** للماك من sideloadly.io وركّبه.
2. نزّل `AbuOdeh.ipa` من: github.com/SamerNajadaUI/thiqa/releases/tag/ios-latest
3. وصّل الآيفون بالماك بالكيبل، واكبس **Trust** على التلفون.
4. افتح Sideloadly، واسحب `AbuOdeh.ipa` عليه، واكتب الـ Apple ID تبعك، واكبس **Start**.
5. على الآيفون: الإعدادات ← عام ← VPN وإدارة الأجهزة ← اكبس على حسابك ← **Trust**.
6. أول مرة بس: الإعدادات ← الخصوصية والأمان ← **Developer Mode** ← شغّله، والتلفون بيعمل ريستارت.

## شغلة لازم تعرفها

حساب آبل المجاني بيخلي التطبيق شغّال **7 أيام**. بعدها بتعيد الخطوة 4، أو بتفعّل
**Automatic Refresh** بـ Sideloadly، وهو بيجدده لحاله لما يكون الماك والتلفون على نفس الواي فاي.
مع اشتراك مطوّر آبل (99 دولار بالسنة) بيضل شغّال سنة كاملة.

## بديل: Xcode

إذا ركّبت Xcode من App Store: `brew install xcodegen`، بعدين `cd ios && xcodegen generate`،
افتح `AbuOdeh.xcodeproj`، اختار حسابك من Signing & Capabilities، ووصّل التلفون واكبس ▶︎.
